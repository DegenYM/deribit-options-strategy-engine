FAQ

常見問題

為什麼叫 Canopy？

樹冠罩在已有的現貨上方，不是把資產搬進平台。樹冠是遮蔭，不是屋頂。

我完全不懂選擇權，能不能用？

可以先讀策略說明。頁面假設你沒學過選擇權，並寫清最大獲利與最大虧損。仍建議你只拿輸得起的錢。

怎麼開始？

註冊後（非候補模式）會開啟最低方案 30 天試用。登入進控制台：填設定、綁 API，再從總覽開始模擬。

API 要開哪些權限？

只要 account:read 與 trade:read_write。不要開 wallet。建議用子帳，並設 IP 白名單。
