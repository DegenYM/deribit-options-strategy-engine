FAQ

開通前會被問到的事

為什麼要先做調查？

Covered Call 需要你已經持有現貨。問卷用來建議方案與 risk tier，避免還沒現貨就開實單。

API 要開哪些權限？

只要 account:read 與 trade:read_write。不要開 wallet。建議用子帳，並設 IP 白名單。

什麼時候才能實單？

Scout 只有 dry-run。Trader／Pro／Desk 須先跑滿 7 天模擬。Live 解鎖後仍可隨時 Pause。

被 call away 會怎樣？

短 call 被行使時，子帳裡的現貨可能被賣掉。這是策略機制，不是系統故障。
