FAQ

常見問題

為什麼叫 Canopy？

樹冠罩在已有的現貨上方，不是把資產搬進平台。樹冠是遮蔭，不是屋頂。

怎麼開始？

登入後進設定：選你的現貨與風險、勾風險揭露、訂閱、貼 API，然後在總覽按 dry-run。跟一般交易機器人一樣，不是闖關問卷。

API 要開哪些權限？

只要 account:read 與 trade:read_write。不要開 wallet。建議用子帳，並設 IP 白名單。

什麼時候才能實單？

Scout 只有模擬。Trader／Pro／Desk 須先跑滿 7 天 dry-run。
