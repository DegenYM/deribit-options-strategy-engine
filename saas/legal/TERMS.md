# Canopy — 服務條款（草案）

版本：0.1｜適用產品：Canopy Covered Call 全托管軟體工具（BYOK）

> 本文件為產品上線前草案，正式效力以律師審閱後版本為準。使用本服務即表示你已閱讀風險揭露。

## 1. 服務性質

本服務提供軟體，協助你在**自己的 Deribit 帳戶**上執行 Covered Call（備兌賣出看漲期權）的掃描、建議式下單與倉位管理。

本服務：

- **不是**證券投資顧問、基金、信託或資產管理服務
- **不**代操資金、**不**保管加密資產、**不**收取管理費或績效費
- **不**承諾任何報酬、APR、勝率或本金安全

交易指令以 Deribit 撮合結果為準。平台的 Pause / Panic 無法保證成交、價格或滑價。

## 2. API 金鑰與權限

你提供 Deribit API Key（建議僅 `account:read` + `trade:read_write`，**不要**開 wallet）。金鑰由你隨時可在 Deribit 撤銷。建議將 Deribit IP 白名單設為本平台出口 IP。

你授權本服務在你的帳戶內為執行 Covered Call 而讀取帳戶、下單、取消與平倉。

## 3. 模擬與實單

新帳戶預設須完成平台規定的 **dry-run（模擬）期間** 後，符合方案條件才可開啟實單。Scout 方案不含實單。

## 4. 費用

訂閱費用依方案頁面與 Stripe 帳單為準（或開發階段標示的測試通路）。交易所手續費、資金費、滑價由你自行承擔。

## 5. 禁止行為

不得將本服務用於洗錢、規避制裁、未經授權操作他人帳戶，或任何違法用途。

## 6. 免責

在法律允許範圍內，本服務按「現況」提供。因市場波動、API 中斷、429、軟體缺陷、設定錯誤或你自己的操作造成的損失，平台不負賠償責任。

## 7. 終止

任一方可隨時終止。終止後我們會停止 worker；請自行在 Deribit 撤銷金鑰並檢查未平倉位。

## 8. 準據法

由營運實體所在地法律管轄（待法人設立後填入）。
